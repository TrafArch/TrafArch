# TrafArch 设计偏好与长期记忆

来源：用户于 2026-11-03 确认的 2.x 优化方案与补充。完整、可执行规范见 [design.md](../design.md)，此处保留后续调整必须遵循的意图。

- 亮色和暗色分别设计，默认亮色主色跟随亮色图标的深靛蓝，暗色更柔和。采用靛蓝／雾靛蓝，辅助青绿和暖琥珀；同一页面需要阶梯色差和重点对比，避免所有区域都是同一种主题色。
- 排版不能只靠加粗，必须拉开字号、行高与留白；正文以 15–16dp 为主，专家字段可保持密度，系统大字体要自然增长。
- 阴影是 Z 轴与用途规范。浅影表达贴面、克制、精密和信息优先，适用于列表卡片、输入框和信息面板；它抗干扰较弱，**浅影必须配细线**。深影吸引注意，表达临时、浮空和模态，适用于菜单、拖动卡片及压过页面的弹层。不同用途分级，不给全部对象套同一种影。
- 阴影色必须随背景／主题变化。暗色不能只加黑影，应同时抬高悬浮表面亮度、加强边线；菜单缩成小图也应与背景分开，不能看成“一饼”。完整阴影不得被组件裁切。
- 卡包使用重新设计的海蓝、青玉、鸢紫、暖铜卡面；余额按**数字部分中心线**纵向对齐，币种标记不能挤偏数字，不采用每行独立缩字造成参差。
- 模式切换条保持状态，选中胶囊应连续滑动并支持反向，详情和知识库也适用；只对下方内容淡入淡出，保留各栏滚动位置。弹窗确认／取消与主界面按钮共用 14dp 圆角。
- 亮色分段底轨要浅，选中胶囊清晰；下拉菜单无外描边，选项有分割线。足迹三指标一行并排。卡包普通字号下余额保持卡名右侧；详情卡面只保留名称、适用的交通联合标识、卡号和余额。首页识别卡片后有向下展开动画，减少动画时直接显示。
- 首页左上角应用标志保持原轮廓，颜色随当前主题／真实系统莫奈变化；不把这一要求扩大为重染官方标识或桌面启动图标。
- 五个主页面仅通过底栏点击切换，保留左右滑动转场与胶囊动画，正文横滑不切功能页；专家内部多栏继续点击选择，横向标签可滚动。子页面预测性返回手势保留。
- 悬浮和下沉底栏均自动避让 Android 小白条；按系统安全区计算，小白条存在时抬高可操作内容。键盘避让不重复计入，正文和提示条同步避让底栏。
- 本轮规范只作用独立 2.x Gallery。真实业务、原始日志、保存快照及数据库禁止因视觉调整改写。有关数据库约束始终以根 AGENTS.md 为准。

后续优化请先读根 design.md 和本文，不再要求用户重复解释以上原则。带日期的历史设计与交接文档保留原状。
