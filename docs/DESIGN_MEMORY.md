# TrafArch 设计偏好与长期记忆

来源：用户于 2026-11-03 确认的 2.x 优化方案与补充。完整、可执行规范见 [design.md](../design.md)，此处保留后续调整必须遵循的意图。

- 亮色和暗色分别设计，默认亮色主色跟随亮色图标的深靛蓝，暗色更柔和。采用靛蓝／雾靛蓝，辅助青绿和暖琥珀；同一页面需要阶梯色差和重点对比，避免所有区域都是同一种主题色。
- 排版不能只靠加粗，必须拉开字号、行高与留白；正文以 15–16dp 为主，专家字段可保持密度，系统大字体要自然增长。
- 阴影是 Z 轴与用途规范。浅影表达贴面、克制、精密和信息优先，适用于列表卡片、输入框和信息面板；它抗干扰较弱，**普通卡片的浅影必须配细线**，悬浮底栏按下述独立规则处理。深影吸引注意，表达临时、浮空和模态，适用于菜单、拖动卡片及压过页面的弹层。不同用途分级，不给全部对象套同一种影。
- 阴影色必须随背景／主题变化。暗色不能只加黑影，应同时抬高悬浮表面亮度、加强边线；菜单缩成小图也应与背景分开，不能看成“一饼”。完整阴影不得被组件裁切。悬浮底栏按用户 2026-11-06 新要求：亮色无框线、加强外轮廓双层阴影，暗色无阴影、加 1dp 主题细边线；保留 78% 不透明度表面与 sigma 14dp 背景模糊，主题切换时平滑过渡。
- 卡包使用提亮的海蓝、青玉、鸢紫、暖铜浅色渐变与深色文字；自选图片保留深色遮罩和白色文字，可主动调用系统相册，图片仅用于当前会话、不上传；用户于 2026-11-06 要求去掉列表内部缩略卡，整行直接使用对应卡面背景，保留放大的左侧非接触图标，卡名和地区／卡种向左移动；右侧菜单为无底无框的 ghost 按钮。余额按**数字部分中心线**纵向对齐，币种标记不能挤偏数字，不采用每行独立缩字造成参差。币种统一放数值前面：CNY ¥、JPY ¥、HKD $、USD $、MOP ¥，共享前缀保留宽度。
- 模式切换条保持状态，选中胶囊应连续滑动并支持反向，详情和知识库也适用；详情只对下方内容淡入淡出，知识库 TU／CU 直接更新内容，不整页刷新或交叉淡化，保留各栏滚动位置。知识库覆盖地区按需构建，地区／线路按实际内容高度放缓展开和收起，长列表不使用统一固定时长。底部弹出卡片统一放缓为 380ms 弹起、300ms 收起，保留减少动画与预测性返回。弹窗确认／取消与主界面按钮共用 14dp 圆角。
- 亮色分段底轨要浅，选中胶囊清晰；下拉菜单无外描边，选项有分割线。卡包普通字号下余额保持卡名右侧；首页、详情与卡面预览共用卡面排版，名称 20／26dp 左上、适用的交通联合标识右上，底部余额 36／44dp 在左、掩码卡号在右。仅详情卡面不加余额标签或读取时间，首页与卡面预览保留辅助说明行。首页识别卡片后以 560ms easeInOutCubic 淡入并平滑调整到结果卡面的高度，减少动画时直接显示；结果卡面与下方内容框保持同宽、左右对齐，按内容自然增高，避免额外拉高和中间大块留白。
- 首页左上角应用标志保持原轮廓，颜色随当前主题／真实系统莫奈变化；不把这一要求扩大为重染官方标识或桌面启动图标。
- 首页按用户 2026-11-06 要求恢复两步读取：初始只有图标、贴卡引导、支持范围和开始读取按钮；点击后以非线性动画过渡到卡片靠近手机背面的动态示意，保留贴卡示意但去掉水波纹，在插画下方显示不伪造百分比的读取进度条，显示贴卡与读取说明及“模拟数据”。失败可重试，减少动画时使用静态贴卡姿态。四个主页面使用统一高度标题栏，行程与卡包不显示副标题。右上角使用常驻浅底按钮组，中间单竖线分隔；设置不随页面转场移动，新图标独立淡入缩放，悬停／按压反馈为圆角方形而非圆形。
- 当前四个可见主页面依次为首页、行程、专家、卡包，仅通过底栏点击切换，保留左右滑动转场与胶囊动画，正文横滑不切功能页；专家内部多栏继续点击选择，横向标签可滚动。子页面预测性返回手势保留。
- 足迹暂时停用，首页、底栏、设置及可见内置场景不提供入口，也不添加启用开关。保留前端、状态与冻结样例以便恢复；原始 52 个场景不删改，可见场景为 51 个。保留前端的三指标仍一行并排。
- 悬浮底栏最大宽度收至 320dp、内容高 62dp；下沉按钮行增至 65dp，底色调浅为普通表面混入 25% 凹陷表面，系统导航区同色，两者点击均不出现黑色涟漪。两种底栏均自动避让 Android 小白条；按系统安全区计算，小白条存在时抬高可操作内容。键盘避让不重复计入，正文和提示条同步避让底栏。
- 本轮规范只作用独立 2.x Gallery。真实业务、原始日志、保存快照及数据库禁止因视觉调整改写。有关数据库约束始终以根 AGENTS.md 为准。
- 用户于 2026-11-06 确认小窗与折叠屏继续保留单列和四项底栏；标题／正文限宽 720dp，实体铰链选最大可用子屏，忽略普通折痕与半折姿态。全部弹层共用窗口坐标和实时菜单锚点；窄窗统一两行标题、必要时图标导航，保留大字和点击区域。卡包按局部宽度重排，分段条／七日图可横滚，矮窗只压缩装饰；缩放保持页面、草稿与任务。captionBar 由现有 Flutter Insets 消费，不加固定顶部高度，不接入厂商姿态通道。完整规则见根 design.md。

后续优化请先读根 design.md 和本文，不再要求用户重复解释以上原则。带日期的历史设计与交接文档保留原状。

2026-11-13 用户新要求覆盖旧提示位置与余额居中规则：悬浮提示压缩上下留白，普通提示最小高 44dp，带操作时通常 48dp；固定在当前窗口右上角，避开顶部与右侧系统安全区，以 240ms 从右侧推出、180ms 向右收回，减少动画时即时完成。保留队列、撤销、主题、大字与长消息滚动。卡包余额整组靠左，币种按实际文字宽度显示后与数字仅隔 4dp，数字左对齐，不再保留共享前缀空位或数字居中产生的间距。
