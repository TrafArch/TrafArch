# Suica 行程金额与余额展示修复

用户反馈行程不显示扣款与余额。最新日志与截图为不同记录集，不能把截图金额当成新日志数值。

用户补充：行程卡片按国内交通卡的展示逻辑，金额使用带正负号的JP￥，右侧为行程后余额；日本轨道交通不进行商务座或其他席别判断。Suica票卡复用通用布局，投影不提供席别；“余额差”来源仍留在详情与冻结JSON，不改写旧捕获。

## 根因与边界

- 090F 相邻完整块的余额已读到，但现有差额计算要求卡内流水严格加1。最新日志铁路条目均跨2流水，三条余额差因此被置空。
- 通用票卡只有 `amountText != null` 才显示 `balanceAfterText`，将独立有效的余额一起隐藏。
- 相邻记录的残高相减可以提供“余额差”，并不证明单笔票价。本轮在详情与冻结 JSON 保留该来源，行程票卡按用户要求只显示带符号的金额；不将余额直接当扣款，不从扫描时间、零初始余额或跨批次记录推断费用。
- 只有同次读取中物理相邻、非空、合法日期和余额、流水严格正向的块参与差额。缺块、无效块、日期倒序、流水倒退/重复/回绕和最旧记录均不补猜差额。原始块、数据库及旧快照不改写。
