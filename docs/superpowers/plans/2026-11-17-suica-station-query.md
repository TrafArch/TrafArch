# Suica 站点查询与日期展示修复

**用户要求：** 修复日本交通卡大量站点未收录、排查时刻缺失，并将 Suica 行程标题显示为“日本轨道交通”。

**已证实根因：** 原 SuicaReader 使用小写、不补零的十六进制字符串查询 `areacode/linecode/stationorder`。源 SQLite 列声明 INTEGER，但含 a–f 的键仍存 TEXT，纯数字十六进制字符串被 affinity 存为 INTEGER。当前直接传入协议字节对应的十进制 int，既漏匹配也可能错误匹配。数据库、清单和原始字节不需要改动。

**时刻边界：** 日志仅读取 090F，共20块、12条非空记录。铁路记录 bytes 6–9 为站码，不包含小时分钟；购物记录使用不同布局。其他公开闸机服务可能含少量最近时刻，本日志没有该服务，不能从现有证据补造时刻。本轮修复当前履历说明，不新增未经本卡验证的跨服务时刻关联。
