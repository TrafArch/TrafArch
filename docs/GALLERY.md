# TrafArch 2.x 界面 Gallery

设计基线为 Demo 2.4.0，采用独立 Flutter 页面、组件、主题和导航；色彩、字体、阴影及交互以根 [design.md](../design.md) 为现行规范，长期偏好见 [设计记忆](DESIGN_MEMORY.md)。正式 NFC、协议、档案与参考数据库不作迁移。

## 运行与切换

正式入口 `lib/main.dart` 默认打开现有界面。在「设置 → 外观 → 启用新界面（beta）」确认后，可进入 2.x 实卡体验；「设置 → 返回现有界面」可切回，重启也回到现有界面。切换等待 NFC 关闭，未确认关闭时留在当前界面并支持重试。

实卡体验已接入首页、行程、专家、卡包和相关设置。由用户点击「开始读取」才开始 NFC；首页保留并标明上次成功摘要，未完成的新读取不能保存，也不进入行程或专家。关闭 NFC 后才准备档案，可手动确认保存或沿用已启用的自动保存与重复卡片策略。

卡包与现有界面共用本机档案；详情包含冻结交易、统计和卡片信息。改名只写自定义名称，删除需要确认且不可撤销。导入需先预览并确认，完整备份与字段 JSON 均走现有本地文件流程，不自动上传。消费统计使用已确认且币种明确的扣款，日期缺失的扣款只进入「全部」的总额和分类，不将 Suica 等余额差当成消费。卡面、排序持久化、扫码、知识库和诊断导出未接入。以下样例、场景和预览构建说明仅适用于独立 `lib/main_gallery.dart` 入口。

```powershell
flutter run -t lib/main_gallery.dart
```

预览入口首次启动先显示 2.x 风格的协议确认弹窗，可点按 EULA 与隐私政策阅读官网全文。同意记录与普通入口共用，仅在本机保存；查看全文、拒绝或按返回键均不视为同意。设置底部“关于 TrafArch”保留两个全文入口。

支持 Firebase 分析的版本会在该弹窗中预选分析开关，点「同意并继续」前不启用采集。可取消选择后继续，也可在「设置 → 隐私 → Firebase 分析」随时更改；不影响本地日志、卡片和行程，界面切换不会重置选择。

独立样例入口确认后默认进入现有界面。在“设置 → 外观”开启“启用新界面（beta）”，新版设置末尾“预览”分区的同名开关可以关闭。重启恢复现有界面；正式入口的同名开关只通往实卡体验，不通往样例。样例入口切换会销毁离开的界面会话，样例不会接收真实卡片或业务设置；预测性返回偏好由宿主单独保存。

新版设置按 spec 2.3 组织为读卡与数据、外观、日志、帮助与支持、关于 TrafArch 与末尾预览分区。About 信息内联展示，不再有独立关于页；样例管理与恢复初始样例入口已移除，冻结数据仍保留全部 52 个场景供内部使用。足迹暂时停用，从首页、底栏和设置隐藏入口，不提供启用开关，页面前端与样例保留供以后恢复。初始首页未读取，卡包含深圳通、Suica、八达通三个样例；悬浮底栏、跟随系统、莫奈系统取色（不可用时回退靛蓝），自动保存／上海透支／日志关闭。模拟读取延迟 1600ms，二维码获取延迟 700ms；重置、进入扫码及离开界面会取消对应任务。应用可见内容统一使用“内置样例”等表述，移除“测试”“演示”和 Demo 版本标签；样例来源与尚未保存文件的提示仍明确保留。

两种底栏按首页、行程、专家、卡包排列四项。悬浮底栏最大宽度为 320dp，使用单个包住图标与文字的选中胶囊，以 180ms 水平移动；连续点击从当前位置转向新目标。项间距 5dp，下沉底栏保留图标指示器。文字与图标仅绘制一次显式颜色过渡，固定字重，无阴影或触摸焦点描边，点击不出现黑色涟漪，键盘焦点单独使用细描边。专家页列表与横向页签保持稳定滚动标识。

悬浮底栏亮色模式无框线，以接触影 y=2、blur=10、alpha=.16 和扩散影 y=8、blur=24、alpha=.14 加强外轮廓；暗色模式无阴影，使用 1dp 主题细边线。阴影绘制在圆角裁切外侧，边线不占用按钮布局空间；主题切换时平滑过渡边线和阴影强度。两种模式均在胶囊范围内以 sigmaX／sigmaY 均为 14dp 的高斯模糊处理背后页面，叠加 78% 不透明度表面。主题、底栏样式及页内分段控件复用单个 180ms 移动滑块，外框 16dp、滑块 13dp 圆角对应 3dp 内边距；横向滚动页签按文本宽度移动。运行日志导出、手动配色和偏好错误区域使用 180ms 高度动画，收起时立即退出交互、焦点和读屏遍历。上述位移动画遵循系统减少动画设置。

详情与知识库切换条保持挂载，选中胶囊以 180ms 连续滑动并支持中途反向；详情共用当前滚动位置，知识库 TU／CU 各自恢复滚动位置。覆盖地区按视口构建，城市与线路沿用共用展开组件：依据内容的实际高度，260ms 展开、220ms 收起并整组淡化，支持中途反向。保存／重命名弹窗按钮与主界面共用 14dp 圆角，禁用状态保持轮廓。

共享行程票据采用用户参考图确认的独立字号配置：日期 26dp、时间 16dp、站名 18dp、方式 16dp、城市 14dp、金额 18dp、线路 13dp；仅日期分组标题加粗，进站／出站端的时间与站名一律常规字重（2026-11-14 起时间减小两号 22→16dp、不再加粗出发时间）。线路徽章不跟随 spec 2.2 颜色引擎，冻结改造前配色（轨道浅靛蓝底深字、公交深靛蓝底白字、上海 1 号线红，含暗色变体）。轨道徽章按消费城市复用既有 54 城市 SVG 及明确别名，保留原色、透明区域、34dp 容器和 23dp 图标；异地用卡仍显示消费城市标志，跨城／未知／无素材及加载失败保留原列车图标，公交不变。不改动城市识别、数据库或冻结样例。

专家页直接展示当前样例类型的信息，不再提供交通卡／银行卡／FeliCa 类型选择器。保存与重命名弹窗按内容收紧，不显示输入标签、尾号行和字符计数；输入仍保留读屏名称、80 字限制及空白校验。

页面与浮层使用 `GalleryMotion` 场景 Token，见[设计规范](../design.md)。底栏同级正文原位交叉淡化 200ms，底栏和标题栏固定，正文横滑不切页；子页以 300／260ms 横向进入／退出。半模态以 320／240ms 上浮／下沉，遮罩最高 40%；贡献者和许可详情可以从 57% 上滑扩展至 90% 或下滑关闭。居中弹窗与锚点菜单分别复用 180／140ms 进入／退出时长，锚点菜单按可用空间反转方向。专家页签仍以 160ms 淡化，详情和知识库分段内容直接更新。首页贴卡示意、读取状态和卡面收缩保留专用动效。退出内容不可交互；减少动态效果时直接显示目标状态。

“设置 → 外观 → 预测性返回手势”默认开启。支持的 Android 系统上，子页随返回手势水平露出上一页，抽屉向下收起；取消后恢复当前内容，提交后才真正返回。优先关闭弹层，再退出二维码获取视图，最后返回子页；主功能根页交给系统退出。关闭选项或系统减少动画时保留普通返回。宿主复用 app_settings.txt 的独立键 gallery_predictive_back_enabled 保存偏好，不写数据库；退出新版、重启和恢复样例均保留选择。读取失败使用默认值，保存失败提示本次选择未保存，两者都提供重试。

设置中的 About 内联在页面底部，包含图标、应用名称、版本与构建号、致谢、开放源代码许可、隐私政策与贡献者；问题反馈仍为独立全屏页面，返回回到设置的原滚动位置。贡献者收起态最多叠放 3 个头像并显示 +N 与人数，整行打开半模态弹层，展示姓名、角色与可验证的个人主页链接，无主页时不显示外链。开放源代码许可保留按视口构建的列表，点击整行打开详情弹层，展示软件名称、按正文识别的许可证类型、可用的原文链接与完整正文；不合并不同版本或不同依赖实例的记录。许可按需读取 Flutter LicenseRegistry，正文在首次打开时解析并在会话内缓存，重复打开与主题切换不重复解析。两个弹层下滑到底、叉号、遮罩与预测性返回共用同一关闭路径，手势取消不重建内容、不丢滚动位置。问题反馈提供 QQ 群、邮箱、问卷及复制操作；浏览器不可用时保留链接与重试入口。公共地址集中在 `lib/shared/app_support.dart`，与现有界面共享。

行程筛选与卡片管理均为贴近触发按钮的下拉菜单，不遮暗背景；筛选左对齐，选中标记位于右侧。卡片菜单提供重命名、更改卡面、删除本卡三项，删除保留确认；导出通过页面工具栏进入。菜单会避让屏幕边缘，支持外部点击、返回键和 Esc 关闭；内置场景也复用同一菜单。

## 运行时设计规范

配色集中于 GalleryPalette／GalleryTokens／GallerySchemeTokens 与 OKLCH 颜色引擎 `gallery_color_engine.dart`，字体集中于 GalleryTypography。六套手动主题与卡面莫奈共用 Canvas、Surface、Container、Outline 与输入语义角色。色值见[设计规范](../design.md)。数据色和固定状态色独立，分类映射固定（轨道→data-1／公交→data-2／其他→data-3）。主题逐角色插值，使用 200ms／easeInOutCubic 全局过渡；减少动态效果时立即更新。

莫奈跟随当前首页卡片：预设渐变卡面直接提供种子，自选图片由 `gallery_monet.dart` 在相册选择完成时有界采样，裁切拖动不重算、`完成` 保存后一次性切换；取消裁切不改主题，取色失败回退当前预设（默认靛蓝），不读取系统壁纸色。首页品牌标志使用原 SVG 轮廓，前景与底色随当前主题变化，启动图标和官方交通联合标识保持原资源。

阴影区分贴面、轻卡片、悬浮与模态；普通卡片轻影配细线，菜单用双层阴影、独立悬浮面和明确边线，暗色同时提高悬浮面亮度；悬浮底栏亮色无框线、加强双层外轮廓阴影，暗色无阴影、加细边线。卡面四套为提亮的海蓝、青玉、鸢紫、暖铜浅色渐变，配深色文字；用户图片卡面保留深色遮罩和白色文字；卡包整行使用对应渐变／自选图片卡面，左侧为 34dp 非接触图标，右侧为无底无框的管理按钮；卡包数字独立于币种，按共同中心线对齐。

两种底栏共享 GalleryNavigationLayout。有效安全区为 max(0, viewPadding.bottom − viewInsets.bottom)，Scaffold 处理键盘高度，底栏不重复计入。悬浮内容高 62dp，底边距为安全区＋18dp；下沉完整按钮行高 65dp，在安全区上方，非零安全区再加 8dp；两者内容高度均随系统字号增高。下沉底栏使用 Surface，选中项使用 Primary Container，系统导航区同色。正文底部留白取底栏总占位＋16dp，提示条取总占位＋12dp；系统安全区不属于按钮点击范围。手势与三键导航均按系统 inset 处理，方向／窗口／键盘变化时重新计算。

卡包普通字号下将金额保留在卡名右侧，金额列共享宽度与缩放；1.5 倍及以上大字体统一改上下布局。币种统一作为前缀显示 CNY ¥、JPY ¥、HKD $、USD $、MOP ¥，各行共享前缀保留宽度，数值按共同中心线对齐，不将币种留在金额后面。未知值保留原语义。

首页、详情与卡面预览共用排版：名称左上 20／26dp，适用的交通联合标识右上；底部两列为余额左侧 36／44dp、掩码卡号右侧，卡号用等宽辅助文字。详情卡面只显示名称、适用标识、卡号和余额；首页与卡面预览保留余额标签、最近读取的原有辅助说明行。长标题和系统大字体自然增高。保留的足迹前端顶部三个指标仍固定一行等宽。分段底轨使用浅表面色，下拉菜单无外描边且选项间有分割线。

## 数据与边界

- 除上述返回手势偏好外，新版设置与所有模拟操作仅在内存生效。
- 所有卡片、行程、证书与原始字节为设计样例。时钟固定为 2026-10-27 09:41 UTC+08:00，二维码样例保留完整 335 字节载荷和 117 字节证书，不执行密码学验签。
- 新版不初始化真实读卡或档案业务依赖，不调用 NFC、相机或文件导出。更换卡面可由用户主动调用 Android 系统照片选择器（不可用时回退系统文件选择器），无需存储权限；所选图片仅用于本次会话，不上传、不写档案数据库。选择取消或失败时保留原卡面，关闭弹层或重置后丢弃迟到结果；图片解码后保存在内存中，不依赖会被下次选择清理的原生缓存。公共支持链接通过内部宿主注入的回调，仅在用户主动点击后调用浏览器或打开邮件应用；不自动填入、上传或提交卡片与日志。复制仅响应用户操作；导出显示“尚未保存文件”的内容预览。
- 日志开关只收集本次启用后的界面动作，不记录卡名、卡号或站点；关闭停止收集。
- 上海样例总余额原值为 86.50 元，默认显示 78.50 元，每次从原值计算，交易金额与原始字节不变。其他卡片和未知余额保持各自语义。
- 消费统计默认全部保留记录，可选本周／本月／本年／自定义日期并切换相邻区间，周期以既有演示时钟为准。总额、日均、分类及趋势使用样例自身币种，Suica 为整数 JPY，八达通为 HK$，未知币种显示暂不可用。全部中的缺失日期扣款保留在总额、分类与明细中，趋势／日均仅使用完整日期，并明确说明；不补写日期、不把充值或过程事件计入消费。详情卡面随滚动连续收为包含名称、尾号和余额的胶囊，与三段切换条共同悬停；自定义图片从内存取色并缓存，原始数据操作置于本区标题右侧。
- 知识库概况和层级浏览仍是 2026-10-30 设计快照（TU 41 地区／7658 编码，CU 7 地区／1732 编码），不是实时统计。标题下的搜索胶囊独立检索当前随包发布的 TU／CU 参考库：校验 manifest 和 SHA256，以只读模式打开，后台构建会话内索引。搜索分类显示城市、线路、站点与原始编码；编码只做精确和前缀匹配。返回保留搜索和浏览位置，输入不联网、不写库、不加入日志。

可离线重新提取设计样例与原始交通联合 SVG：

```powershell
node dev/gallery/extract_demo.cjs '<TrafArch-UI-Redesign 目录>'
```

该脚本仅读取设计 HTML 和场景目录，更新专用 Gallery 资产，不访问或修改发布 SQLite。官方交通联合标识由 `flutter_svg` 直接渲染本地原始 SVG，保持比例与原色。

## 构建与验证

签名配置继续使用仓库外的 `key.properties` 和对应 keystore。为构建进程设置 `TRAFARCH_SIGNING_PROPERTIES`，然后执行：

```powershell
flutter build apk --release -t lib/main_gallery.dart --target-platform android-arm64 --split-per-abi
```

内部 target 默认应用 Google Services 并包含 Firebase Analytics，可在确实需要离线预览包时通过 `--android-project-arg galleryAnalytics=false` 显式关闭。现有界面关闭自动更新检查。名称固定 TrafArch，包名固定 `com.kajolno.TrafArch`，主版本名沿用源码，每次生成安装包预留下一构建号；当前 Gradle 使用 `force-version-code-ignoring-abi=true`，Android versionCode 与源码本次构建号一致，不叠加 ABI 偏移。最终仍核验 AAB/APK 实际清单、证书、对齐和 SHA256。

打包前检查各分支已消耗的构建号及可用交付／设备记录，选择尚未使用的新号。核验时明确传入本次源码构建号与最新已消耗 Android 版本码基线，不以历史固定版本码代替升级比较：

```powershell
python -X utf8 dev/gallery/verify_apk.py '<APK路径>' --build-tools '<Android build-tools目录>' --output '<核验输出目录>' --expected-build-number <本次构建号> --min-version-code <已消耗版本码基线>
```

脚本核验版本名、名称、包名、arm64 ABI、构建号与实际 versionCode 一致、原签名、Release 标记、Gallery 资产、Firebase 自动初始化与 Analytics 组件存在、ZIP CRC／16KiB 对齐及每个原生库的 ELF LOAD 对齐。调用时通过 `--expected-version-name` 传入当前版本名。输出 `apk-verification.json` 与 `SHA256SUMS.txt`，任一检查失败均以非零状态退出；核验报告不代表已完成设备安装。

```powershell
flutter test
flutter analyze
```

### Windows Flutter 3.47.x 测试进程访问冲突（历史）

2026-11-15 本机已升级至 Flutter 3.50.0／Dart 3.14.0，标准 `flutter test` 恢复正常，下列临时入口仅保留为 3.47.x 历史对照，勿在 3.50 上使用。

Flutter 3.47.7／Dart 3.13.5 的 `flutter_tester.exe` 会间歇性以 `-1073741819`（`0xC0000005`）退出，剩余用例显示 `did not complete`。默认测试启动的 Dart CPU 性能采样器与官方问题 [dart-lang/sdk#64627](https://github.com/dart-lang/sdk/issues/64627) 的受影响版本一致；当前对照实验支持该原因，尚未捕获本机崩溃栈。不要把这一现象直接描述为 Android 应用闪退，也不要通过跳过断言或删除测试规避。

在仓库根目录，可用下列临时入口执行相同测试：

```powershell
./dev/gallery/test_windows.ps1 --concurrency=2 --reporter expanded
./dev/gallery/test_windows.ps1 test/gallery_controller_test.dart test/gallery_ui_test.dart test/beta_ui_switch_test.dart --concurrency=1 --reporter expanded
```

脚本从 PATH 定位 Flutter，将 SDK 专用启动器模板复制到 `build/gallery/`，使用 SDK 自身的包配置，只移除 Windows `flutter_tester` 的 `--enable-dart-profiling`。Flutter 引擎在该开关缺席时关闭 CPU 采样；测试发现、断言、超时与结果退出码保持原流程。脚本不修改 SDK 或应用构建，使用私有 Flutter 工具接口并限定于 Windows Flutter 3.47.1–3.47.7。本次证据见 [测试退出排查记录](GALLERY_TEST_DIAGNOSIS_20261101.md)。

回归覆盖 52 个场景状态、模拟读取／保存／编辑／删除、余额设置、筛选、二维码取消和重置隔离、新旧界面切换、触摸交互与大字体布局；另覆盖页面与弹层动画中间帧、底栏深浅色像素、快速反向切页覆盖、折叠、页签滚动恢复、预测性返回取消／提交、偏好跨宿主恢复及读写失败重试。设置页专项覆盖 spec 2.3 信息架构、About 内联、样例管理移除、贡献者收起／展开与外链可用性、许可类型识别与长正文弹层、半模态 57%／90% 上下限、下滑关闭和预测性返回取消后的高度与滚动位置保留。自动化验证不代表 Android 真机视觉与系统手势验收；本轮未连接设备；安装包核验结果及实际构建号以交付报告为准。

### 本地截图复核

Windows 上可使用本机微软雅黑、Consolas 和 Material Icons 生成独立 PNG。截图只显示 Flutter 界面，系统小白条以 24dp 安全区进行布局模拟，不代表 Android 真机帧率验收。

```powershell
$env:GALLERY_CAPTURE_DIR = Join-Path (Get-Location) 'build/gallery/review'
./dev/gallery/test_windows.ps1 test/gallery_visual_review_test.dart --concurrency=1 --reporter expanded
```

常规测试跳过此可选截图入口，不要求开发机安装 Windows 字体。设计回归另见 gallery_design_test.dart 和 gallery_navigation_design_test.dart，涵盖实际对比度、主题插值、手势、莫奈刷新、金额几何及系统安全区。
