# TrafArch 2.x 界面 Gallery

设计基线为 Demo 2.4.0，采用独立 Flutter 页面、组件、主题和导航；色彩、字体、阴影及交互以根 [design.md](../design.md) 为现行规范，长期偏好见 [设计记忆](DESIGN_MEMORY.md)。正式 NFC、协议、档案与参考数据库不作迁移。

## 运行与切换

```powershell
flutter run -t lib/main_gallery.dart
```

默认进入现有界面。在“设置 → 外观”开启“启用新界面（beta）”，新版设置中的同名开关可以关闭。重启恢复现有界面；普通 `lib/main.dart` 入口不显示内部开关。切换会销毁离开的界面会话，新版不会接收真实卡片或业务设置；预测性返回偏好由宿主单独保存。

新版“设置 → 样例管理 → 内置场景”提供 51 个可见的确定性场景和恢复初始样例。冻结数据保留全部 52 个场景；足迹暂时停用，从首页、底栏、设置与内置场景隐藏入口，不提供启用开关，页面前端与样例保留供以后恢复。初始首页未读取，卡包含深圳通、Suica、八达通三个样例；悬浮底栏、跟随系统、莫奈系统取色（不可用时回退靛蓝），自动保存／上海透支／日志关闭。模拟读取延迟 1600ms，二维码获取延迟 700ms；重置、进入扫码及离开界面会取消对应任务。应用可见内容统一使用“内置样例”等表述，移除“测试”“演示”和 Demo 版本标签；样例来源与尚未保存文件的提示仍明确保留。

两种底栏按首页、行程、专家、卡包排列四项。悬浮底栏最大宽度为 320dp，使用单个包住图标与文字的选中胶囊，以 180ms 水平移动；连续点击从当前位置转向新目标。项间距 5dp，下沉底栏保留图标指示器。文字与图标仅绘制一次显式颜色过渡，固定字重，无阴影或触摸焦点描边，点击不出现黑色涟漪，键盘焦点单独使用细描边。专家页列表与横向页签保持稳定滚动标识。

悬浮底栏亮色模式无框线，以接触影 y=2、blur=10、alpha=.16 和扩散影 y=8、blur=24、alpha=.14 加强外轮廓；暗色模式无阴影，使用 1dp 主题细边线。阴影绘制在圆角裁切外侧，边线不占用按钮布局空间；主题切换时平滑过渡边线和阴影强度。两种模式均在胶囊范围内以 sigmaX／sigmaY 均为 14dp 的高斯模糊处理背后页面，叠加 78% 不透明度表面。主题、底栏样式及页内分段控件复用单个 180ms 移动滑块，外框 16dp、滑块 13dp 圆角对应 3dp 内边距；横向滚动页签按文本宽度移动。运行日志导出、手动配色和偏好错误区域使用 180ms 高度动画，收起时立即退出交互、焦点和读屏遍历。上述位移动画遵循系统减少动画设置。

详情与知识库切换条保持挂载，选中胶囊以 180ms 连续滑动并支持中途反向；详情下方内容直接切换，取消各栏独立滚动记忆，使用一个当前滚动位置，最近交易按视口布局；知识库 TU／CU 直接更新内容，各栏仍独立恢复滚动位置。知识库覆盖地区按视口按需构建，页面位移在重绘边界外执行以复用绘制结果；地区及线路展开／收起按实际内容高度计算时长（280ms＋每 dp 高度 0.35ms，最多 1200ms），支持中途反向。保存／重命名弹窗按钮与主界面共用 14dp 圆角，禁用状态保持轮廓。

专家页直接展示当前样例类型的信息，不再提供交通卡／银行卡／FeliCa 类型选择器。保存与重命名弹窗按内容收紧，不显示输入标签、尾号行和字符计数；输入仍保留读屏名称、80 字限制及空白校验。

页面与浮层的基础动画采用无弹跳的 easeOutCubic：主页面正文按底栏顺序左右滑动 240ms，跨项直达目标，底栏与统一高度的标题栏固定；行程与卡包移除副标题，交易总览及滚动胶囊改为显示当前卡名。右上角统一浅底圆角操作组，设置按钮常驻，仅新增扫码／导出图标以 280ms 淡入缩放、160ms 退出，组宽平滑变化；主页面仅由底栏点击切换，正文左右滑动不切换功能页；保留胶囊平滑移动，专家内部栏位仍仅点击切换，横向标签条可滚动。子页进入／返回为 280／220ms，上一页保持静止；全部底部弹出卡片上浮／下沉为 380／300ms，遮罩同步变化；居中弹窗淡入并从 0.96 倍恢复／反向退出为 180／140ms；下拉菜单展开／关闭为 180／120ms，菜单实体从锚点侧轻微缩放、位移并淡入，阴影随实体运动；普通折叠高度与箭头旋转为 180ms，覆盖地区和线路折叠时长随内容高度变化；首页初始引导与读取提示分两步呈现；开始后以 560ms easeInOutCubicEmphasized 过渡到手机背面贴卡示意，2800ms 贴卡循环不再带水波纹，下方显示不伪造百分比的读取进度条，减少动画时静止；首页识别后的卡片区域以 560ms easeInOutCubic 淡入并平滑调整高度，结果卡面与下方行程框保持同宽和左右对齐，按内容自然增高，保留首页列表状态；专家页内页签淡入淡出为 160ms，详情与知识库直接更新内容。退出中的内容禁止交互。系统减少动画时取消非必要位移、缩放与等待；主页面点击切换与识别卡片后展开均直接显示目标状态。

“设置 → 外观 → 预测性返回手势”默认开启。支持的 Android 系统上，子页随返回手势水平露出上一页，抽屉向下收起；取消后恢复当前内容，提交后才真正返回。优先关闭弹层，再退出二维码获取视图，最后返回子页；主功能根页交给系统退出。关闭选项或系统减少动画时保留普通返回。宿主复用 app_settings.txt 的独立键 gallery_predictive_back_enabled 保存偏好，不写数据库；退出新版、重启和恢复样例均保留选择。读取失败使用默认值，保存失败提示本次选择未保存，两者都提供重试。

设置中的“关于”和“问题反馈”为独立全屏页面，沿用新版配色、圆角和排版，返回回到设置的原滚动位置。关于包含图标、版本、作者、致谢、开放源代码许可和隐私政策；致谢与许可也使用独立页面。许可按需读取 Flutter LicenseRegistry。问题反馈提供 QQ 群、邮箱、问卷及复制操作；浏览器不可用时保留链接与重试入口。公共地址集中在 `lib/shared/app_support.dart`，与现有界面共享。

行程筛选与卡片管理均为贴近触发按钮的下拉菜单，不遮暗背景；筛选左对齐，选中标记位于右侧。卡片菜单提供重命名、更改卡面、删除本卡三项，删除保留确认；导出通过页面工具栏进入。菜单会避让屏幕边缘，支持外部点击、返回键和 Esc 关闭；内置场景也复用同一菜单。

## 运行时设计规范

配色集中于 GalleryPalette／GalleryTokens，字体角色集中于 GalleryTypography，五套手动主题保留原 ID。运行时不再读取冻结 fixtures 的旧色板。默认亮色用亮色图标同系的深靛蓝，暗色用柔和雾靛蓝，另设青绿和琥珀强调；普通卡片、凹陷控件和悬浮表面分级。ColorScheme 和状态色逐角色插值。

莫奈由锁定的 dynamic_color 1.9.x 只读获取系统颜色，应用恢复前台时刷新。可用时保留系统主色及容器配对，不可用时回退靛蓝；关闭后恢复手动主题。首页品牌标志使用原 SVG 轮廓，前景与底色随当前主题变化，启动图标和官方交通联合标识保持原资源。

阴影区分贴面、轻卡片、悬浮与模态；普通卡片轻影配细线，菜单用双层阴影、独立悬浮面和明确边线，暗色同时提高悬浮面亮度；悬浮底栏亮色无框线、加强双层外轮廓阴影，暗色无阴影、加细边线。卡面四套为提亮的海蓝、青玉、鸢紫、暖铜浅色渐变，配深色文字；用户图片卡面保留深色遮罩和白色文字；卡包整行使用对应渐变／自选图片卡面，左侧为 34dp 非接触图标，右侧为无底无框的管理按钮；卡包数字独立于币种，按共同中心线对齐。

两种底栏共享 GalleryNavigationLayout。有效安全区为 max(0, viewPadding.bottom − viewInsets.bottom)，Scaffold 处理键盘高度，底栏不重复计入。悬浮内容高 62dp，底边距为安全区＋18dp；下沉完整按钮行高 65dp，在安全区上方，非零安全区再加 8dp；两者内容高度均随系统字号增高。下沉底色调浅为普通表面混入 25% 凹陷表面，系统导航区同色。正文底部留白取底栏总占位＋16dp，提示条取总占位＋12dp；系统安全区不属于按钮点击范围。手势与三键导航均按系统 inset 处理，方向／窗口／键盘变化时重新计算。

卡包普通字号下将金额保留在卡名右侧，金额列共享宽度与缩放；1.5 倍及以上大字体统一改上下布局。币种统一作为前缀显示 CNY ¥、JPY ¥、HKD $、USD $、MOP ¥，各行共享前缀保留宽度，数值按共同中心线对齐，不将币种留在金额后面。未知值保留原语义。

首页、详情与卡面预览共用排版：名称左上 20／26dp，适用的交通联合标识右上；底部两列为余额左侧 36／44dp、掩码卡号右侧，卡号用等宽辅助文字。详情卡面只显示名称、适用标识、卡号和余额；首页与卡面预览保留余额标签、最近读取的原有辅助说明行。长标题和系统大字体自然增高。保留的足迹前端顶部三个指标仍固定一行等宽。分段底轨使用浅表面色，下拉菜单无外描边且选项间有分割线。

## 数据与边界

- 除上述返回手势偏好外，新版设置与所有模拟操作仅在内存生效。
- 所有卡片、行程、证书与原始字节为设计样例。时钟固定为 2026-10-27 09:41 UTC+08:00，二维码样例保留完整 335 字节载荷和 117 字节证书，不执行密码学验签。
- 新版不创建业务依赖或数据库，不调用 NFC、相机或文件导出。更换卡面可由用户主动调用 Android 系统照片选择器（不可用时回退系统文件选择器），无需存储权限；所选图片仅用于本次会话，不上传、不写档案数据库。选择取消或失败时保留原卡面，关闭弹层或重置后丢弃迟到结果；图片解码后保存在内存中，不依赖会被下次选择清理的原生缓存。公共支持链接通过内部宿主注入的回调，仅在用户主动点击后调用浏览器或打开邮件应用；不自动填入、上传或提交卡片与日志。复制仅响应用户操作；导出显示“尚未保存文件”的内容预览。
- 日志开关只收集本次启用后的界面动作，不记录卡名、卡号或站点；关闭停止收集。
- 上海样例总余额原值为 86.50 元，默认显示 78.50 元，每次从原值计算，交易金额与原始字节不变。其他卡片和未知余额保持各自语义。
- 消费统计默认全部保留记录，可选本周／本月／本年／自定义日期并切换相邻区间，周期以既有演示时钟为准。总额、日均、分类及趋势使用样例自身币种，Suica 为整数 JPY，八达通为 HK$，未知币种显示暂不可用。全部中的缺失日期扣款保留在总额、分类与明细中，趋势／日均仅使用完整日期，并明确说明；不补写日期、不把充值或过程事件计入消费。详情卡面随滚动连续收为包含名称、尾号和余额的胶囊，与三段切换条共同悬停；自定义图片从内存取色并缓存，原始数据操作置于本区标题右侧。
- 知识库为 2026-10-30 的设计快照，TU 41 地区／7658 编码，CU 7 地区／1732 编码，保留来源与 SHA256；不是当前发布数据库的实时统计。

可离线重新提取设计样例与原始交通联合 SVG：

```powershell
node dev/gallery/extract_demo.cjs '<TrafArch-UI-Redesign 目录>'
```

该脚本仅读取设计 HTML 和场景目录，更新专用 Gallery 资产，不访问或修改发布 SQLite。官方交通联合标识由 `flutter_svg` 直接渲染本地原始 SVG，保持比例与原色。

## 构建与验证

签名配置继续使用仓库外的 `key.properties` 和对应 keystore。为构建进程设置 `TRAFARCH_SIGNING_PROPERTIES`，然后执行：

```powershell
flutter build apk --release -t lib/main_gallery.dart --target-platform android-arm64 --split-per-abi
```

内部 target 排除 Google Services 和 Firebase Analytics，现有界面关闭自动更新检查。名称固定 TrafArch，包名固定 `com.kajolno.TrafArch`，主版本名沿用源码，每次生成安装包预留下一构建号；当前 Gradle 使用 `force-version-code-ignoring-abi=true`，Android versionCode 与源码本次构建号一致，不叠加 ABI 偏移。最终仍核验 APK 实际清单、证书、对齐和 SHA256。

打包前检查各分支已消耗的构建号及可用交付／设备记录，选择尚未使用的新号。核验时明确传入本次源码构建号与最新已消耗 Android 版本码基线，不以历史固定版本码代替升级比较：

```powershell
python -X utf8 dev/gallery/verify_apk.py '<APK路径>' --build-tools '<Android build-tools目录>' --output '<核验输出目录>' --expected-build-number <本次构建号> --min-version-code <已消耗版本码基线>
```

脚本核验版本名、名称、包名、arm64 ABI、构建号与实际 versionCode 一致、原签名、Release 标记、Gallery 资产、Firebase 自动组件缺席、ZIP CRC／16KiB 对齐及每个原生库的 ELF LOAD 对齐。调用时通过 `--expected-version-name` 传入当前版本名。输出 `apk-verification.json` 与 `SHA256SUMS.txt`，任一检查失败均以非零状态退出；核验报告不代表已完成设备安装。

```powershell
flutter test
flutter analyze
```

### Windows Flutter 3.47.x 测试进程访问冲突

本机 Flutter 3.47.7／Dart 3.13.5 的 `flutter_tester.exe` 会间歇性以 `-1073741819`（`0xC0000005`）退出，剩余用例显示 `did not complete`。默认测试启动的 Dart CPU 性能采样器与官方问题 [dart-lang/sdk#64627](https://github.com/dart-lang/sdk/issues/64627) 的受影响版本一致；当前对照实验支持该原因，尚未捕获本机崩溃栈。不要把这一现象直接描述为 Android 应用闪退，也不要通过跳过断言或删除测试规避。

在仓库根目录，可用下列临时入口执行相同测试：

```powershell
./dev/gallery/test_windows.ps1 --concurrency=2 --reporter expanded
./dev/gallery/test_windows.ps1 test/gallery_controller_test.dart test/gallery_ui_test.dart test/beta_ui_switch_test.dart --concurrency=1 --reporter expanded
```

脚本从 PATH 定位 Flutter，将 SDK 专用启动器模板复制到 `build/gallery/`，使用 SDK 自身的包配置，只移除 Windows `flutter_tester` 的 `--enable-dart-profiling`。Flutter 引擎在该开关缺席时关闭 CPU 采样；测试发现、断言、超时与结果退出码保持原流程。脚本不修改 SDK 或应用构建，使用私有 Flutter 工具接口并限定于 Windows Flutter 3.47.1–3.47.7；SDK 升级后须重新审阅并优先恢复标准 `flutter test`。本次证据见 [测试退出排查记录](GALLERY_TEST_DIAGNOSIS_20261101.md)。

回归覆盖 52 个场景状态、模拟读取／保存／编辑／删除、余额设置、筛选、二维码取消和重置隔离、新旧界面切换、触摸交互与大字体布局；另覆盖页面与弹层动画中间帧、底栏深浅色像素、快速反向切页覆盖、折叠、页签滚动恢复、预测性返回取消／提交、偏好跨宿主恢复及读写失败重试。自动化验证不代表 Android 真机视觉与系统手势验收；本轮未连接设备；安装包核验结果及实际构建号以交付报告为准。
