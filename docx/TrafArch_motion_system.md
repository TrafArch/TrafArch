# TrafArch Motion 1.0

适用范围：Flutter 2.x 界面，对应 `2.7_spec.md`。动效表达层级、状态和方向，不延迟操作。路由、滚动位置与业务状态不由过时的动画完成回调决定。

## 基础 Token

- `GalleryMotion` 集中定义 100／160／220／300／400ms 基础时长与场景时长。搜索防抖 280ms 是输入调度，不属于动效。
- 常规变化用 `easeInOutCubic`，进入用 `easeOutCubic`，退出用 `easeInCubic`（反向驱动时使用镜像曲线）。跟手进度保持线性。
- 局部位移尺度为 2／4／8／16dp；菜单和面板使用 6dp。完整页面和半模态根据视口推进。不引入无明确用途的弹跳、旋转和循环。
- 优先级：系统导航手势 > 当前交互 > 内部状态变化 > 装饰。减少动态效果时直接显示目标态，保留焦点、语义、队列和返回。

## 场景与实现

| 场景 | 进入／退出 | 运行规则 |
| --- | --- | --- |
| 折叠面板 | 260／220ms，箭头 200ms | 依据实际布局高度调整尺寸，整组淡入淡出，内容进入 +6→0dp、退出 0→−2dp。各层独立，反向从当前高度和偏移继续。关闭中的内容不可操作。 |
| 半模态 | 320／240ms | 自底部平移，内容淡入与最高 40% 遮罩同步，无缩放。贡献者和许可详情为可拖动版本：57% 中位、90% 展开、42% 触发关闭。固定内容弹层不强制接受下滑；卡面裁切中返回先退出编辑。 |
| 锚点菜单 | 180／140ms | 根据触发器与可用空间向上或向下打开，进入 .96→1，完全打开后退出 1→.98，6dp 局部位移并淡化。支持外点、键盘和返回。 |
| 层级导航 | 300／260ms | 新子页从右推进，父页轻微左移；返回复原。用稳定路由条目保留搜索词和滚动位置。预测性返回取消恢复原页，提交后才弹栈。 |
| 同级底栏 | 200ms | 正文原位交叉淡化；底栏和标题栏固定，仍只允许点击切换。快速反向从当前不透明度继续。 |
| 悬浮提示 | 240／180ms | 从下方 8dp 归位，退出向下 4dp。保持右上安全区和窗口级队列，支持成功、失败、信息、警告及手动关闭。 |
| 按钮／颜色 | 100ms／200ms | 共用按钮轻缩至 .98，不改变布局；主题用一次全局缓动更新语义色，不重建搜索输入。 |

首页贴卡示意、分段选择胶囊和跟随滚动的卡面属于已有专用交互，不强制套页面转场。共享元素转场为可选增强，本轮不新增。

## 验证边界

Flutter 测试覆盖快速反向、返回手势取消和提交、遮罩及拖动、减少动态效果、主题切换、搜索状态和滚动恢复。模拟手势不等于 Android 真机验证；低端机帧率、输入法与系统级预测返回仍需设备验收。
