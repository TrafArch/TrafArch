# TrafArch

基于 Flutter + Android Kotlin NFC 的交通卡读取与分析工具。

## 核心功能

### 卡片识读

- **交通联合卡（T-Union）**：读取电子钱包余额、公共应用信息、持卡人信息、管理信息、交易明细，以及 SFI 0x1A / 0x1E 乘车过程记录
- **城市一卡通（CU）**：地区卡号识别与卡内数据解析
- **银行卡（EMV / PBOC）**：只读分析应用选择（FCI）、GPO（AIP / AFL）与 TLV 标签数据
- 贴卡即读：Android 原生 Reader Mode 轮询 NFC-A/B/F/V，ISO-DEP APDU 通信

### **CU与EMV/PBOC部分待完善**

### 乘车码解析

- 支持交通部二维码（JT/T 1179）：首页扫码或从相册导入
- 默认调用 Google Play 服务系统扫码，应用无需相机与存储权限
- 无 Google Play 服务 / 离线时，自动回退应用内相机与纯 Dart 解码

### 分析与展示

- 卡片识别：发卡机构指纹 + 城市代码 + 卡号前缀，输出识别置信度与证据链
- 行程重建：过程记录与交易按时间 / 金额配对，解码终端编号并匹配线路与站点
- JT/T 978 符合性检查
- 专家视图：全字段信息、交通数据解析、APDU 日志与过程记录原始数据

### 卡片档案

- 已读卡片保存为档案，记录余额快照与交易记录
- 支持自定义卡片名称、查看详情、删除档案与导出记录

### 数据与设置

- 内置知识库：卡号前缀、发卡机构指纹、终端解码规则、CU / TU 站点数据
- 支持在线更新公开数据，本地快照持久化
- 运行日志可开关记录，一键导出到下载目录
- Material 3 动态取色、深色模式、中英文本地化

## 设备要求

| 项目 | 要求 |
| --- | --- |
| 系统版本 | Android 8.0（API 26）及以上，推荐 Android 17 |
| 读卡硬件 | 支持 NFC 的 Android 手机（读取交通卡 / 银行卡必需） |
| 扫码硬件 | 摄像头（普通扫码）；无 Google Play 服务时仍可离线解码 |
| 网络 | 可选，仅在线更新知识库时需要 |
